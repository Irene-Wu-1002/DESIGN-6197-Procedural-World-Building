## What goes here

- **Case studies** — how a shipped game or film generated its world, and which parts are
  worth borrowing
- **Technique comparisons** — evaluating approaches against each other, for example
  Perlin versus Worley noise for terrain, or Houdini Engine versus native Unreal PCG
- **Post-mortems** — what worked and what did not in my own builds, including performance
  numbers where relevant
- **Reading responses** — notes on assigned papers and articles

## Format

Each analysis states what is being examined, the criteria used to judge it, the evidence
(images, timings, node graphs), and a conclusion about how it changes my own approach.
Aim for a specific claim rather than a summary.

## Naming

Use `topic-analysis.md`, for example `no-mans-sky-terrain-analysis.md`.
