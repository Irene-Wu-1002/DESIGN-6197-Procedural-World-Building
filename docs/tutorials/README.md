# Tutorials

[← Documentation index](../README.md)

Step-by-step guides I write while learning a tool or technique. Writing the process down
is how I confirm I actually understand it, and it means I can rebuild a setup months later
without re-deriving it.

## Contents

- [`react-setup.md`](react-setup.md) — installing React with Vite, written for someone new
  to both React and the command line.
- [`Firebase setup.md`](Firebase%20setup.md) — connecting the Vite prototype to Firebase
  and Firestore without storing generated voxel data.

## What goes here

- Houdini: SOP/VOP workflows, HDA authoring, procedural terrain and scattering
- Unreal Engine: PCG graphs, landscape and material setup, Houdini Engine round-tripping
- Blender: geometry nodes and asset prep
- Web: React, three.js, and browser-based procedural experiments
- Python and scripting utilities

## Format

Each tutorial should be reproducible by someone who has not seen it before:

1. **Goal** — what you will have built by the end, ideally with a result image
2. **Prerequisites** — software versions and assumed knowledge
3. **Steps** — numbered, with parameter values called out explicitly
4. **Result** — screenshot or render of the finished setup
5. **Notes and pitfalls** — what broke the first time and how I fixed it

## Naming

Use `tool-topic.md`, for example `houdini-scatter-basics.md` or `unreal-pcg-forest.md`.
