## Note Structure

Detailed class notes should include:

1. assignment objectives;
2. concepts and terminology;
3. implementation decisions;
4. screenshots or diagrams;
5. evidence that the criteria were addressed;
6. limitations and next steps;
7. links to relevant code, plans, or tutorials.
