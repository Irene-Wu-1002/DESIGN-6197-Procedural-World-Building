# Debug Techniques

### Print to Console
Log events and state changes to trace when and why things happen.
![[w11-debug-print-to-console.png]]
### Select objects / inspect data
Click an entity to see its live properties (transform, state, components) in a panel.
![[w11-debug-select-objects.png]]
![[w11-debug-select-objects1.png]]
### Highlight entities by type
Color-code or outline every object of a class to show what the simulation is made of.
![[week-11-debug-highlight.png]]
![[week-11-debug-highlight1.png]]
![[week-11-debug-highlight2.png]]
### Data structure visualization
Draw the underlying structure (grid, graph, tree, array) in the 3D world.
![[week-11-debug-data-structure.png]]
![[week-11-debug-data-structure1.png]]![[week-11-debug-data-structure2.png]]
### Turn layers on and off
Hide or show groups of objects to separate the scene's systems.
![[week-11-debug-turn-layers-on.png]]
### Visual debugging / viz modes
Switch rendering to show hidden data such as normals, depth, wireframe or IDs instead of the final look.
![[Coursework-Cornell-AAP-IT/docs/assets/screenshots/week-11-debug-visual-debugging.png]]![[week-11-debug-visual-debugging 1.png]]
### Demonstrate procedural content
Show the rules and parameters behind generated content, not just the result
![[week-11-debug-demonstrate-procedural-content.png]]
### Demonstrate Firebase integration
Make the data flow between the database and the scene visible in real time.
![[week-11-debug-firebase-integration.png]]
### Show/hide skeleton
Draw bones and joints to show how a rigged mesh is driven.
![[week-11-debug-show-hide-skeleton.png]]
### Show/hide animation curves/cycles
Show key frames, blend weights and loop timing behind the motion.
![[week-11-debug-show-hide-animation.png]]![[week-11-debug-show-hide-animation1.png]]
### Show/hide pathfinding
Draw the navigation graph, explored nodes and final path an agent picked.
![[week-11-debug-show-hide-pathfinding.png]]
### Build the level step by step (timelapse)
Animate construction piece by piece to show the order the scene is assembled in
![[week-11-debug-build-the-level-step-by-step.png]]
