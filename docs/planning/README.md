# Planning

Project direction, scope, and scheduling.

## Contents

- [`backlog.md`](backlog.md) — running list of features I want to implement, ordered by
  priority.

## What goes here

- Project briefs and scope definitions for each assignment
- Milestone schedules and weekly plans
- Technical design notes written *before* building (node graph sketches, parameter plans,
  data flow diagrams)
- Reference and mood boards with notes on what specifically I want to reproduce

## Naming

Use `YYYY-MM-DD-short-title.md` for dated plans so files sort chronologically. Documents
that are continuously updated, like the backlog, keep a plain descriptive name.
